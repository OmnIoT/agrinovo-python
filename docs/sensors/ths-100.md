# THS-100: Temperature and humidity sensor

Class `agrinovo.THS100`. [Product page](https://agrinovo.io/products/sensors/environmental/ths-100-rs485-temperature-humidity-sensor/) · [Datasheet](https://agrinovo.io/datasheets/sensors/AGRINOVO-THS-100_Datasheet.pdf)

## Wiring

| Wire | Connect to |
|:--|:--|
| Red | Supply + (5-28 V DC) |
| Black | Supply ground |
| Yellow | RS485 A |
| Green | RS485 B |

A and B go to the A and B terminals of the RS485 adapter. When the adapter has a ground terminal, join it to the supply ground.

## Values

`read()` returns these, by name:

| Name | Value | Unit | Register | Stored as |
|:--|:--|:--|:--|:--|
| `temperature` | Temperature | °C | 0x0001 | signed 16-bit, x 0.1 |
| `humidity` | Humidity | % RH | 0x0000 | unsigned 16-bit, x 0.1 |

The sensor is read with function 0x03, 2 registers from 0x0000, at 9600 baud 8N1. Factory address: 1.

## Settings and calibration

| Method | What it does |
|:--|:--|
| `change_address(new_address)` | Gives the sensor a new Modbus address and keeps talking to it there. |
| `set_temperature_offset(degrees)` | Trims the temperature reading against a reference, in °C. |

A method returns once the sensor has confirmed the command and raises `agrinovo.AgrinovoError` when it has not.

## Example

```python
"""Agrinovo THS-100 temperature and humidity sensor.

Prints temperature and humidity every 5 seconds.

Sensor cable
  Red     supply +, 5-28 V DC
  Black   supply ground
  Yellow  RS485 A
  Green   RS485 B

The computer talks to the sensor through a USB to RS485 adapter: A to A,
B to B. Run this file with the adapter's port, for example:

    python ths_100.py /dev/ttyUSB0

https://agrinovo.io/products/sensors/environmental/ths-100-rs485-temperature-humidity-sensor/
"""

import sys
import time

import agrinovo

PORT = sys.argv[1] if len(sys.argv) > 1 else "/dev/ttyUSB0"

with agrinovo.Bus(PORT, baudrate=9600) as bus:
    sensor = agrinovo.THS100(bus)  # Modbus address 1
    while True:
        try:
            reading = sensor.read()
            print(f"Temperature: {reading.temperature:.1f} °C")
            print(f"Humidity: {reading.humidity:.1f} % RH")
        except agrinovo.AgrinovoError as error:
            print(error)
        time.sleep(5)
```
