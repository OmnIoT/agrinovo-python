# GF-201-CO2: Carbon dioxide gas detector

Class `agrinovo.GF201CO2`. [Product page](https://agrinovo.io/products/sensors/environmental/gf-201-co2-gas-sensor/) · [Datasheet](https://agrinovo.io/datasheets/sensors/AGRINOVO-GF-201-CO2_Datasheet.pdf)

## Wiring

| Terminal | Connect to |
|:--|:--|
| 24V+ | Supply + (12-30 V DC) |
| GND | Supply ground |
| A+ | RS485 A |
| B- | RS485 B |

A and B go to the A and B terminals of the RS485 adapter. When the adapter has a ground terminal, join it to the supply ground.

## Values

`read()` returns these, by name:

| Name | Value | Unit | Register | Stored as |
|:--|:--|:--|:--|:--|
| `carbon_dioxide` | Carbon dioxide | ppm | 0x0000 | unsigned 16-bit |

The sensor is read with function 0x03, 1 register from 0x0000, at 9600 baud 8N1. Factory address: 1.

The scaling is that of the standard 0-5000 ppm detector. On a detector ordered with another range, register 0x0011 holds the number of decimal places. The Modbus address is set from the detector's front panel.

## Example

```python
"""Agrinovo GF-201-CO2 carbon dioxide gas detector.

Prints carbon dioxide every 5 seconds.

Sensor terminals
  24V+  supply +, 12-30 V DC
  GND   supply ground
  A+    RS485 A
  B-    RS485 B

The computer talks to the sensor through a USB to RS485 adapter: A to A,
B to B. Run this file with the adapter's port, for example:

    python gf_201_co2.py /dev/ttyUSB0

https://agrinovo.io/products/sensors/environmental/gf-201-co2-gas-sensor/
"""

import sys
import time

import agrinovo

PORT = sys.argv[1] if len(sys.argv) > 1 else "/dev/ttyUSB0"

with agrinovo.Bus(PORT, baudrate=9600) as bus:
    sensor = agrinovo.GF201CO2(bus)  # Modbus address 1
    while True:
        try:
            reading = sensor.read()
            print(f"Carbon dioxide: {reading.carbon_dioxide:.0f} ppm")
        except agrinovo.AgrinovoError as error:
            print(error)
        time.sleep(5)
```
