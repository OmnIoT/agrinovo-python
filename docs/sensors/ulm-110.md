# ULM-110: Explosion-proof ultrasonic level meter

Class `agrinovo.ULM110`. [Product page](https://agrinovo.io/products/sensors/sillo/ulm-110-explosion-proof-ultrasonic-level-meter/) · [Datasheet](https://agrinovo.io/datasheets/sensors/AGRINOVO-ULM-110_Datasheet.pdf)

## Wiring

| Terminal | Connect to |
|:--|:--|
| 1 | Supply + (24 V DC) |
| 2 | Supply ground |
| 5 | RS485 A |
| 6 | RS485 B |

A and B go to the A and B terminals of the RS485 adapter. When the adapter has a ground terminal, join it to the supply ground.

## Values

`read()` returns these, by name:

| Name | Value | Unit | Register | Stored as |
|:--|:--|:--|:--|:--|
| `level` | Level or distance | cm | 0x0000 | 16-bit, top bit is the sign |

The sensor is read with function 0x03, 1 register from 0x0000, at 9600 baud 8N1. Factory address: 1.

The meter reports level or distance, whichever its measurement mode is set to, in the unit chosen in its menu (centimetres from the factory).

## Example

```python
"""Agrinovo ULM-110 explosion-proof ultrasonic level meter.

Prints level or distance every 5 seconds.

Sensor terminals
  1  supply +, 24 V DC
  2  supply ground
  5  RS485 A
  6  RS485 B

The computer talks to the sensor through a USB to RS485 adapter: A to A,
B to B. Run this file with the adapter's port, for example:

    python ulm_110.py /dev/ttyUSB0

https://agrinovo.io/products/sensors/sillo/ulm-110-explosion-proof-ultrasonic-level-meter/
"""

import sys
import time

import agrinovo

PORT = sys.argv[1] if len(sys.argv) > 1 else "/dev/ttyUSB0"

with agrinovo.Bus(PORT, baudrate=9600) as bus:
    sensor = agrinovo.ULM110(bus)  # Modbus address 1
    while True:
        try:
            reading = sensor.read()
            print(f"Level or distance: {reading.level:.0f} cm")
        except agrinovo.AgrinovoError as error:
            print(error)
        time.sleep(5)
```
