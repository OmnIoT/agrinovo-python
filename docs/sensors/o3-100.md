# O3-100: Dissolved ozone probe

Class `agrinovo.O3100`. [Product page](https://agrinovo.io/products/sensors/aqua/ion-selective/o3-100-ozone-probe/) · [Datasheet](https://agrinovo.io/datasheets/sensors/AGRINOVO-O3-100_Datasheet.pdf)

## Wiring

| Wire | Connect to |
|:--|:--|
| Red | Supply + (12-24 V DC) |
| Black | Supply ground |
| Green | RS485 A |
| White | RS485 B |

A and B go to the A and B terminals of the RS485 adapter. When the adapter has a ground terminal, join it to the supply ground.

## Values

`read()` returns these, by name:

| Name | Value | Unit | Register | Stored as |
|:--|:--|:--|:--|:--|
| `ozone` | Ozone | mg/L | 0x0000 | float, low word first |
| `electrode_signal` | Electrode signal | mV | 0x0004 | float, low word first |
| `temperature` | Temperature | °C | 0x0008 | float, low word first |

The sensor is read with function 0x03, 10 registers from 0x0000, at 9600 baud 8N1. Factory address: 1.

## Settings and calibration

| Method | What it does |
|:--|:--|
| `change_address(new_address)` | Gives the sensor a new Modbus address and keeps talking to it there. |
| `calibrate_slope(mg_per_litre)` | Calibrates the slope with the probe in a standard solution of this concentration. Do this before the zero point. |
| `calibrate_zero()` | Calibrates the zero point with the probe in ozone-free water. |
| `calibration_status()` | Progress of the calibration: 0 done, 1 still running, 2 no valid standard, 3 signal unstable, 4 sensor out of limits. |
| `clear_calibration()` | Erases the calibration. |

A method returns once the sensor has confirmed the command and raises `agrinovo.AgrinovoError` when it has not.

## Example

```python
"""Agrinovo O3-100 dissolved ozone probe.

Prints ozone, electrode signal and temperature every 5 seconds.

Sensor cable
  Red    supply +, 12-24 V DC
  Black  supply ground
  Green  RS485 A
  White  RS485 B

The computer talks to the sensor through a USB to RS485 adapter: A to A,
B to B. Run this file with the adapter's port, for example:

    python o3_100.py /dev/ttyUSB0

https://agrinovo.io/products/sensors/aqua/ion-selective/o3-100-ozone-probe/
"""

import sys
import time

import agrinovo

PORT = sys.argv[1] if len(sys.argv) > 1 else "/dev/ttyUSB0"

with agrinovo.Bus(PORT, baudrate=9600) as bus:
    probe = agrinovo.O3100(bus)  # Modbus address 1
    while True:
        try:
            reading = probe.read()
            print(f"Ozone: {reading.ozone:.2f} mg/L")
            print(f"Electrode signal: {reading.electrode_signal:.2f} mV")
            print(f"Temperature: {reading.temperature:.1f} °C")
        except agrinovo.AgrinovoError as error:
            print(error)
        time.sleep(5)
```
