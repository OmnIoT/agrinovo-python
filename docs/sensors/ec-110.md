# EC-110: Conductivity and salinity probe

Class `agrinovo.EC110`. [Product page](https://agrinovo.io/products/sensors/aqua/ec/ec-110-probe/) · [Datasheet](https://agrinovo.io/datasheets/sensors/AGRINOVO-EC-110_Datasheet.pdf)

## Wiring

| Wire | Connect to |
|:--|:--|
| Red | Supply + (12-24 V DC) |
| Black | Supply ground |
| Yellow | RS485 A |
| Green | RS485 B |

A and B go to the A and B terminals of the RS485 adapter. When the adapter has a ground terminal, join it to the supply ground.

## Values

`read()` returns these, by name:

| Name | Value | Unit | Register | Stored as |
|:--|:--|:--|:--|:--|
| `conductivity` | Conductivity | µS/cm | 0x0000 | unsigned 16-bit, x 10 |
| `temperature` | Temperature | °C | 0x0001 | unsigned 16-bit, x 0.1 |
| `tds` | TDS | ppm | 0x0002 | unsigned 16-bit, x 10 |
| `salinity` | Salinity | ppt | 0x0003 | unsigned 16-bit, x 0.1 |

The sensor is read with function 0x03, 4 registers from 0x0000, at 9600 baud 8N1. Factory address: 1.

## Settings and calibration

| Method | What it does |
|:--|:--|
| `change_address(new_address)` | Gives the sensor a new Modbus address and keeps talking to it there. |

A method returns once the sensor has confirmed the command and raises `agrinovo.AgrinovoError` when it has not.

## Example

```python
"""Agrinovo EC-110 conductivity and salinity probe.

Prints conductivity, temperature, TDS and salinity every 5 seconds.

Sensor cable
  Red     supply +, 12-24 V DC
  Black   supply ground
  Yellow  RS485 A
  Green   RS485 B

The computer talks to the sensor through a USB to RS485 adapter: A to A,
B to B. Run this file with the adapter's port, for example:

    python ec_110.py /dev/ttyUSB0

https://agrinovo.io/products/sensors/aqua/ec/ec-110-probe/
"""

import sys
import time

import agrinovo

PORT = sys.argv[1] if len(sys.argv) > 1 else "/dev/ttyUSB0"

with agrinovo.Bus(PORT, baudrate=9600) as bus:
    probe = agrinovo.EC110(bus)  # Modbus address 1
    while True:
        try:
            reading = probe.read()
            print(f"Conductivity: {reading.conductivity:.0f} µS/cm")
            print(f"Temperature: {reading.temperature:.1f} °C")
            print(f"TDS: {reading.tds:.0f} ppm")
            print(f"Salinity: {reading.salinity:.1f} ppt")
        except agrinovo.AgrinovoError as error:
            print(error)
        time.sleep(5)
```
