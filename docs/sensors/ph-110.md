# PH-110: Industrial pH sensor

Class `agrinovo.PH110`. [Product page](https://agrinovo.io/products/sensors/aqua/ph/ph-110-probe/) · [Datasheet](https://agrinovo.io/datasheets/sensors/AGRINOVO-PH-110_Datasheet.pdf)

## Wiring

| Wire | Connect to |
|:--|:--|
| Red | Supply + (12-24 V DC) |
| Black | Supply ground |
| Green | RS485 A |
| Yellow | RS485 B |

A and B go to the A and B terminals of the RS485 adapter. When the adapter has a ground terminal, join it to the supply ground.

## Values

`read()` returns these, by name:

| Name | Value | Unit | Register | Stored as |
|:--|:--|:--|:--|:--|
| `ph` | pH | pH | 0x0000 | unsigned 16-bit, x 0.01 |

The sensor is read with function 0x03, 1 register from 0x0000, at 9600 baud 8N1. Factory address: 1.

## Settings and calibration

| Method | What it does |
|:--|:--|
| `change_address(new_address)` | Gives the sensor a new Modbus address and keeps talking to it there. |
| `calibrate918()` | Calibrates with the sensor in pH 9.18 buffer, once the reading is stable. |
| `calibrate686()` | Calibrates with the sensor in pH 6.86 buffer, once the reading is stable. |
| `calibrate400()` | Calibrates with the sensor in pH 4.00 buffer, once the reading is stable. |

A method returns once the sensor has confirmed the command and raises `agrinovo.AgrinovoError` when it has not.

## Example

```python
"""Agrinovo PH-110 industrial pH sensor.

Prints pH every 5 seconds.

Sensor cable
  Red     supply +, 12-24 V DC
  Black   supply ground
  Green   RS485 A
  Yellow  RS485 B

The computer talks to the sensor through a USB to RS485 adapter: A to A,
B to B. Run this file with the adapter's port, for example:

    python ph_110.py /dev/ttyUSB0

https://agrinovo.io/products/sensors/aqua/ph/ph-110-probe/
"""

import sys
import time

import agrinovo

PORT = sys.argv[1] if len(sys.argv) > 1 else "/dev/ttyUSB0"

with agrinovo.Bus(PORT, baudrate=9600) as bus:
    sensor = agrinovo.PH110(bus)  # Modbus address 1
    while True:
        try:
            reading = sensor.read()
            print(f"pH: {reading.ph:.2f} pH")
        except agrinovo.AgrinovoError as error:
            print(error)
        time.sleep(5)
```
