# CHL-100: Chlorophyll probe

Class `agrinovo.CHL100`. [Product page](https://agrinovo.io/products/sensors/aqua/chlorophyll/chl-100-chlorophyll-probe/) · [Datasheet](https://agrinovo.io/datasheets/sensors/AGRINOVO-CHL-100_Datasheet.pdf)

## Wiring

| Wire | Connect to |
|:--|:--|
| Brown | Supply + (12-24 V DC) |
| Black | Supply ground |
| Blue | RS485 A |
| White | RS485 B |

A and B go to the A and B terminals of the RS485 adapter. When the adapter has a ground terminal, join it to the supply ground.

## Values

`read()` returns these, by name:

| Name | Value | Unit | Register | Stored as |
|:--|:--|:--|:--|:--|
| `chlorophyll` | Chlorophyll | µg/L | 0x2602 | float, least significant byte first |
| `temperature` | Temperature | °C | 0x2600 | float, least significant byte first |

The sensor is read with function 0x03, 4 registers from 0x2600, at 9600 baud 8N1. Factory address: 1.

## Settings and calibration

| Method | What it does |
|:--|:--|
| `change_address(new_address)` | Gives the sensor a new Modbus address and keeps talking to it there. |
| `start_brush()` | Runs the cleaning brush once. |

A method returns once the sensor has confirmed the command and raises `agrinovo.AgrinovoError` when it has not.

## Example

```python
"""Agrinovo CHL-100 chlorophyll probe.

Prints chlorophyll and temperature every 5 seconds.

Sensor cable
  Brown  supply +, 12-24 V DC
  Black  supply ground
  Blue   RS485 A
  White  RS485 B

The computer talks to the sensor through a USB to RS485 adapter: A to A,
B to B. Run this file with the adapter's port, for example:

    python chl_100.py /dev/ttyUSB0

https://agrinovo.io/products/sensors/aqua/chlorophyll/chl-100-chlorophyll-probe/
"""

import sys
import time

import agrinovo

PORT = sys.argv[1] if len(sys.argv) > 1 else "/dev/ttyUSB0"

with agrinovo.Bus(PORT, baudrate=9600) as bus:
    probe = agrinovo.CHL100(bus)  # Modbus address 1
    while True:
        try:
            reading = probe.read()
            print(f"Chlorophyll: {reading.chlorophyll:.2f} µg/L")
            print(f"Temperature: {reading.temperature:.1f} °C")
        except agrinovo.AgrinovoError as error:
            print(error)
        time.sleep(5)
```
