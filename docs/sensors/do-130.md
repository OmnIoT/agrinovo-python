# DO-130: Self-cleaning dissolved oxygen probe

Class `agrinovo.DO130`. [Product page](https://agrinovo.io/products/sensors/aqua/do/do-130-self-cleaning-probe/) · [Datasheet](https://agrinovo.io/datasheets/sensors/AGRINOVO-DO-130_Datasheet.pdf)

## Wiring

| Wire | Connect to |
|:--|:--|
| Red | Supply + (12-24 V DC) |
| Black | Supply ground |
| White | RS485 A |
| Green | RS485 B |

A and B go to the A and B terminals of the RS485 adapter. When the adapter has a ground terminal, join it to the supply ground.

## Values

`read()` returns these, by name:

| Name | Value | Unit | Register | Stored as |
|:--|:--|:--|:--|:--|
| `dissolved_oxygen` | Dissolved oxygen | mg/L | 0x0000 | float, least significant byte first |
| `temperature` | Temperature | °C | 0x0002 | float, least significant byte first |

The sensor is read with function 0x03, 4 registers from 0x0000, at 9600 baud 8N1. Factory address: 1.

## Settings and calibration

| Method | What it does |
|:--|:--|
| `change_address(new_address)` | Gives the sensor a new Modbus address and keeps talking to it there. |
| `start_brush()` | Runs the cleaning brush once. The cycle takes 3 to 5 seconds. |
| `set_brush_interval(seconds)` | Sets how often the brush cleans by itself, in seconds. |
| `set_salinity(ppt)` | Sets the salinity of the water, in ppt, for the oxygen compensation. |

A method returns once the sensor has confirmed the command and raises `agrinovo.AgrinovoError` when it has not.

## Example

```python
"""Agrinovo DO-130 self-cleaning dissolved oxygen probe.

Prints dissolved oxygen and temperature every 5 seconds.

Sensor cable
  Red    supply +, 12-24 V DC
  Black  supply ground
  White  RS485 A
  Green  RS485 B

The computer talks to the sensor through a USB to RS485 adapter: A to A,
B to B. Run this file with the adapter's port, for example:

    python do_130.py /dev/ttyUSB0

https://agrinovo.io/products/sensors/aqua/do/do-130-self-cleaning-probe/
"""

import sys
import time

import agrinovo

PORT = sys.argv[1] if len(sys.argv) > 1 else "/dev/ttyUSB0"

with agrinovo.Bus(PORT, baudrate=9600) as bus:
    probe = agrinovo.DO130(bus)  # Modbus address 1
    while True:
        try:
            reading = probe.read()
            print(f"Dissolved oxygen: {reading.dissolved_oxygen:.2f} mg/L")
            print(f"Temperature: {reading.temperature:.2f} °C")
        except agrinovo.AgrinovoError as error:
            print(error)
        time.sleep(5)
```
