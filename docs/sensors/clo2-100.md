# CLO2-100: Chlorine dioxide probe

Class `agrinovo.CLO2100`. [Product page](https://agrinovo.io/products/sensors/aqua/ion-selective/cl02-100-chloride-dioxide-probe/) · [Datasheet](https://agrinovo.io/datasheets/sensors/AGRINOVO-CLO2-100_Datasheet.pdf)

## Wiring

| Wire | Connect to |
|:--|:--|
| Red | Supply + (9-27 V DC) |
| Black | Supply ground |
| Green | RS485 A |
| White | RS485 B |

A and B go to the A and B terminals of the RS485 adapter. When the adapter has a ground terminal, join it to the supply ground.

## Values

`read()` returns these, by name:

| Name | Value | Unit | Register | Stored as |
|:--|:--|:--|:--|:--|
| `chlorine_dioxide` | Chlorine dioxide | mg/L | 0x0000 | float, low word first |
| `electrode_signal` | Electrode signal | mV | 0x0004 | float, low word first |
| `temperature` | Temperature | °C | 0x0008 | float, low word first |

The sensor is read with function 0x03, 10 registers from 0x0000, at 9600 baud 8N1. Factory address: 1.

## Settings and calibration

| Method | What it does |
|:--|:--|
| `change_address(new_address)` | Gives the sensor a new Modbus address and keeps talking to it there. |

A method returns once the sensor has confirmed the command and raises `agrinovo.AgrinovoError` when it has not.

## Example

```python
"""Agrinovo CLO2-100 chlorine dioxide probe.

Prints chlorine dioxide, electrode signal and temperature every 5 seconds.

Sensor cable
  Red    supply +, 9-27 V DC
  Black  supply ground
  Green  RS485 A
  White  RS485 B

The computer talks to the sensor through a USB to RS485 adapter: A to A,
B to B. Run this file with the adapter's port, for example:

    python clo2_100.py /dev/ttyUSB0

https://agrinovo.io/products/sensors/aqua/ion-selective/cl02-100-chloride-dioxide-probe/
"""

import sys
import time

import agrinovo

PORT = sys.argv[1] if len(sys.argv) > 1 else "/dev/ttyUSB0"

with agrinovo.Bus(PORT, baudrate=9600) as bus:
    probe = agrinovo.CLO2100(bus)  # Modbus address 1
    while True:
        try:
            reading = probe.read()
            print(f"Chlorine dioxide: {reading.chlorine_dioxide:.2f} mg/L")
            print(f"Electrode signal: {reading.electrode_signal:.2f} mV")
            print(f"Temperature: {reading.temperature:.1f} °C")
        except agrinovo.AgrinovoError as error:
            print(error)
        time.sleep(5)
```
