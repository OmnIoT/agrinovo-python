# NH3-100: Ammonia nitrogen probe

Class `agrinovo.NH3100`. [Product page](https://agrinovo.io/products/sensors/aqua/ion-selective/nh3-100-probe/) · [Datasheet](https://agrinovo.io/datasheets/sensors/AGRINOVO-NH3-100_Datasheet.pdf)

## Wiring

| Wire | Connect to |
|:--|:--|
| Red | Supply + (12-24 V DC) |
| Black | Supply ground |
| Yellow | RS485 A |
| White | RS485 B |

A and B go to the A and B terminals of the RS485 adapter. When the adapter has a ground terminal, join it to the supply ground.

## Values

`read()` returns these, by name:

| Name | Value | Unit | Register | Stored as |
|:--|:--|:--|:--|:--|
| `ammonia` | Ammonia nitrogen | mg/L | 0x0000 | float, low word first |
| `electrode_signal` | Electrode signal | mV | 0x0002 | float, low word first |
| `temperature` | Temperature | °C | 0x0008 | float, low word first |

The sensor is read with function 0x03, 10 registers from 0x0000, at 9600 baud 8N1. Factory address: 1.

## Settings and calibration

| Method | What it does |
|:--|:--|
| `change_address(new_address)` | Gives the sensor a new Modbus address and keeps talking to it there. |
| `calibrate(standard_code)` | Starts a calibration point with the probe in a standard solution. Standard codes: 0x0002 = 0.1 ppm, 0x0004 = 1 ppm, 0x0008 = 10 ppm, 0x0010 = 100 ppm, 0x0020 = 1000 ppm. |
| `calibration_status()` | Progress of the calibration point: 0 done, 1 still running, 2 no valid standard, 3 signal unstable, 4 electrode out of limits. |
| `clear_calibration()` | Erases every calibration point. |

A method returns once the sensor has confirmed the command and raises `agrinovo.AgrinovoError` when it has not.

## Example

```python
"""Agrinovo NH3-100 ammonia nitrogen probe.

Prints ammonia nitrogen, electrode signal and temperature every 5 seconds.

Sensor cable
  Red     supply +, 12-24 V DC
  Black   supply ground
  Yellow  RS485 A
  White   RS485 B

The computer talks to the sensor through a USB to RS485 adapter: A to A,
B to B. Run this file with the adapter's port, for example:

    python nh3_100.py /dev/ttyUSB0

https://agrinovo.io/products/sensors/aqua/ion-selective/nh3-100-probe/
"""

import sys
import time

import agrinovo

PORT = sys.argv[1] if len(sys.argv) > 1 else "/dev/ttyUSB0"

with agrinovo.Bus(PORT, baudrate=9600) as bus:
    probe = agrinovo.NH3100(bus)  # Modbus address 1
    while True:
        try:
            reading = probe.read()
            print(f"Ammonia nitrogen: {reading.ammonia:.2f} mg/L")
            print(f"Electrode signal: {reading.electrode_signal:.1f} mV")
            print(f"Temperature: {reading.temperature:.1f} °C")
        except agrinovo.AgrinovoError as error:
            print(error)
        time.sleep(5)
```
