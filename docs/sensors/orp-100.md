# ORP-100: ORP probe

Class `agrinovo.ORP100`. [Product page](https://agrinovo.io/products/sensors/aqua/orp/orp-100-probe/) · [Datasheet](https://agrinovo.io/datasheets/sensors/AGRINOVO-ORP-100_Datasheet.pdf)

## Wiring

| Wire | Connect to |
|:--|:--|
| Red | Supply + (12-24 V DC) |
| Black | Supply ground |
| Yellow | RS485 A |
| Green | RS485 B |

A and B go to the A and B terminals of the RS485 adapter. When the adapter has a ground terminal, join it to the supply ground.

## Values

`read()` returns these, by name:

| Name | Value | Unit | Register | Stored as |
|:--|:--|:--|:--|:--|
| `orp` | ORP | mV | 0x0000 | signed 16-bit |

The sensor is read with function 0x03, 1 register from 0x0000, at 9600 baud 8N1. Factory address: 1.

## Settings and calibration

| Method | What it does |
|:--|:--|
| `change_address(new_address)` | Gives the sensor a new Modbus address and keeps talking to it there. |
| `set_offset(millivolts)` | Sets the calibration offset in mV: the value of the standard solution minus the reading in it. |

A method returns once the sensor has confirmed the command and raises `agrinovo.AgrinovoError` when it has not.

## Example

```python
"""Agrinovo ORP-100 ORP probe.

Prints ORP every 5 seconds.

Sensor cable
  Red     supply +, 12-24 V DC
  Black   supply ground
  Yellow  RS485 A
  Green   RS485 B

The computer talks to the sensor through a USB to RS485 adapter: A to A,
B to B. Run this file with the adapter's port, for example:

    python orp_100.py /dev/ttyUSB0

https://agrinovo.io/products/sensors/aqua/orp/orp-100-probe/
"""

import sys
import time

import agrinovo

PORT = sys.argv[1] if len(sys.argv) > 1 else "/dev/ttyUSB0"

with agrinovo.Bus(PORT, baudrate=9600) as bus:
    probe = agrinovo.ORP100(bus)  # Modbus address 1
    while True:
        try:
            reading = probe.read()
            print(f"ORP: {reading.orp:.0f} mV")
        except agrinovo.AgrinovoError as error:
            print(error)
        time.sleep(5)
```
